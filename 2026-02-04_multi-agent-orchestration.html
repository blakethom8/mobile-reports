  • Shadow agents: Monitor other agents' work in real-time
  • Reviewers: Dedicated agents that check code quality
  • Trajectories: Save context/decisions so future agents understand why things were done

4. The Problems

  • Lazy work: Agents declare tasks "done" but leave TODOs/stubs
  • Overwhelmed Leads: Too many agents → Lead gets flooded → enters death spiral
  • Context loss: Without trajectories, agents repeat mistakes or redo work
