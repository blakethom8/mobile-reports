📈 Coverage Improvements

The narrative summary now comprehensively covers:

  1. Education & Training — Medical school, residency, fellowships, years in practice
  2. Clinical Focus — Specialties, subspecialties, board certifications
  3. Research Profile — Academic publications, clinical trials, teaching roles (when available)
  4. Practice Affiliations — Hospitals, medical groups, health system relationships
  5. Practice Type — Solo, group, hospital-employed, academic, independent
  6. Notable Services — Specific procedures or specialized care offered
  7. Web Presence — Website quality, online reputation, patient reviews

All of this is synthesized from multiple data sources including Google Places, NPPES, Brave Search, SearchAPI (web + scholar), and direct website crawling.

🔍 Data Pipeline Architecture

Summary Generation Flow

  1. Enrichment Phase — Collect data from multiple APIs (Google, Brave, NPPES, SearchAPI)
  2. Web Crawling — Crawl provider website for detailed content (up to 12 pages)
  3. Context Assembly — Combine all data sources into structured payload
  4. LLM Synthesis — Claude Sonnet 4.5 generates narrative from context
  5. Storage — Save summary + context to database with 30-day TTL
  6. Caching — Redis cache for fast retrieval on subsequent loads

💡 Key Decisions & Rationale

  • Scholar search only for comprehensive depth — Balances data quality with API cost. Most users will use standard depth; comprehensive is for thorough due diligence.
  • Narrative summary as hero — Research shows users prefer readable summaries over technical data dumps. The narrative tells a story, makes providers memorable.
  • Collapsible sections for details — Progressive disclosure keeps the page scannable while preserving access to deep data for power users.
  • Web scraping + LLM synthesis — Automated approach scales better than manual curation. LLM can extract insights from crawled content that structured APIs miss.
  • Target length (200-300 words) — Long enough to be comprehensive, short enough to stay focused. Prevents rambling or padding.
