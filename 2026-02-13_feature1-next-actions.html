1. Backend: Intelligence Router

File: api/routers/intelligence.py
Endpoint: POST /api/intelligence/next-actions
Lines: ~270 LOC

Scoring Algorithm

The recommendation engine uses a multi-factor scoring system (0-100 scale):

Factor Weight Logic
Status Priority Base score Hard Lead: 100
Soft Lead: 80
Existing: 60
Non-Target: 20
Does Not Exist: 0
Recency +30 max 60+ days: +30 (very overdue)
30-60 days: +20 (overdue)
14-30 days: +10 (slightly overdue)
7-14 days: +5 (recent)
<7 days: -10 (very recent)
Never contacted: +25 (if lead)
Engagement +15 max 10+ notes: +15
5-10 notes: +10
2-5 notes: +5

Key Functions

  • _calculate_days_since() - Date math for recency scoring
  • _status_priority_score() - Base score by relationship stage
  • _calculate_score() - Comprehensive scoring with all factors
  • _generate_reason() - Human-readable explanation of recommendation
  • get_next_actions() - Main endpoint handler with Pro protection

🎨 User Experience Flow

For Pro Users

  1. Visit My Providers: Navigate to the CRM dashboard
  2. See Widget: "Today's Priorities" appears above provider list (if providers exist)
  3. View Recommendations: Top 5 providers shown with:
    • Priority ranking (1-5)
    • Provider name and specialty
    • Location (city, state)
    • Status badge (Hard Lead, Soft Lead, etc.)
    • Score (0-100)

⚠️ Technical Considerations

Performance

  • Current: Scores calculated on-demand for each request
  • Scale Concern: For users with 500+ providers, calculation could slow down
  • Solution: Consider pre-computing scores nightly and caching results

Test Coverage Gaps

  • Integration tests marked as @pytest.mark.skip - need FastAPI TestClient setup
  • No frontend tests yet (consider adding React Testing Library tests)
  • Pro plan protection tested in unit tests, needs integration validation

Database Queries

  • Current implementation makes multiple Supabase queries (statuses, notes, practices)
  • Consider SQL JOIN optimization for better performance
  • Add database indexes on user_id and practice_status_id

UX Polish Opportunities
