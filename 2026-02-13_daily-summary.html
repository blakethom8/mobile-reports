💡 Lessons Learned

🎓 Cron Job Safety (for future reference)

  • Never schedule overlapping jobs - Space 90+ minutes apart minimum
  • Always check if work already done - Don't retry completed tasks
  • Use lock files - Prevent simultaneous repo access (.openclaw-lock)
  • Stop containers during automated work - Avoid HMR storms
  • Only run during off-hours - 10 PM - 8 AM PST when Blake isn't working
  • Exit successfully when work is done - Don't error out on existing branches
  • One job at a time - Sequential execution, never concurrent
