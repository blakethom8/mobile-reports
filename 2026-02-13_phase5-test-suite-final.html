🚀 Test Activation Guide

Priority 1: CRM Tests (30-45 minutes)

File: api/tests/test_crm_routes.py (14 tests)

Steps:
  1. Remove pytestmark = pytest.mark.skip(...) line
  2. Remove @patch decorator imports
  3. For each test method:
    • Replace client parameter with pro_client
    • Remove @patch decorators
    • Remove mock_db, mock_user parameters
    • Simplify assertions (stub returns data automatically)
  4. Run: pytest api/tests/test_crm_routes.py -v
